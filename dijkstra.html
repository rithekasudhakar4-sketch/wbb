Understanding Dijkstra's Algorithm in Nalam Nagar

Created by Edsger W. Dijkstra in 1956, this algorithm solves the single-source shortest path problem on graphs with non-negative edge weights.

1

Initialization

Assign tentative distance values: 0.0 minutes to the start zone, and ∞ (infinity) to all other 11 zones. Add the start zone to the Priority Queue.

2

Greedy Min Selection

Always extract the unvisited zone with the smallest tentative travel time from the Min-Priority Queue. Because all road travel times are positive, this extracted distance is guaranteed to be optimal.

3

Edge Relaxation

For each open road leaving zone u to neighbor v: calculate alternative time dist[u] + travelTime(u, v). If this is faster than dist[v], update dist[v] and set prev[v] = u.

4

Early Termination

When the destination zone is popped from the Priority Queue, the shortest path is mathematically settled. The algorithm halts immediately without wasting cycles exploring irrelevant branches.

5

Path Reconstruction

Starting at the destination, backtrack through the previous pointers to reconstruct the exact turn-by-turn route, total mileage (km), and cumulative response ETA (minutes).

⏱️ Time Complexity: O((V + E) log V)

Our Java implementation uses a binary heap (java.util.PriorityQueue). With V = 12 zones and E = 16 roads (32 directed edges), the route planner settles any path across the town in under 0.1 milliseconds.

🚑 How Dijkstra Powers Nalam Nagar Dispatches

Every emergency triggers Dijkstra twice:
• Leg 1 (Ambulance ➔ Patient): Evaluates all available vehicle stations to dispatch the fastest ambulance.
• Leg 2 (Patient ➔ Hospital): Calculates the fastest route to a facility equipped with matching medical specialties and free beds.
